# Personal Portfolio Website

-->This repository contains the source code for my **Personal Portfolio Website**.

-->This portfolio website showcases my **skills, projects, resume, and contact information** through a clean and responsive user interface. It highlights my experience in AI/ML development, Large Language Model (LLM) integrations, cloud-native applications, and full-stack development, demonstrating my ability to design and build intelligent, scalable, and modern software solutions.

## 🌐 Live Preview

You can deploy this portfolio using **GitHub Pages**, **Netlify**, or **Vercel**.

## 📌 Features

* Responsive personal portfolio website
* Modern and clean UI design
* Dark mode support
* Smooth scrolling navigation
* Skills and project showcase
* Resume download option
* Contact section

## 🛠️ Technologies Used

* **HTML5** – Structure of the website
* **CSS3 / SCSS** – Styling and layout
* **JavaScript** – Interactive functionality
* **Responsive Design** – Mobile-friendly layout
